# Сценарий

Правила хуков, оценки и ритма адаптированы из `studio-script` (Melvynx/video-agent-skills, MIT — см. `NOTICE.md`) под наш канал: озвучка голосом, русский язык, хук всегда через боль, тире в озвучке остаются (паузы голоса).

## Объём и темп

- 30–40 с ≈ **75–80 слов** (ElevenLabs, speed 1.2 ≈ 2,2 слова/с, паузы между сценами 0.22 с).
- Одна идея на ролик. Нужно «а ещё…» — это второй ролик.
- 6–9 сцен по 3–6 с. Что-то меняется на экране минимум каждые 4–5 с; первая смена — до 5-й секунды.
- Строка = один вдох: 4–12 слов, не дольше 4 с. Конкретика вместо абстракции (название, цифра, сцена). Никогда три абстрактные строки подряд — третья становится примером.
- Обращение на «ты», к одному человеку. Короткие слова: чего не скажешь другу — вычёркивай. Без «уникальный», «революционный», «инновационный».

## Хук — всегда через боль

первая фраза называет боль зрителя, вторая обещает, что она решается. Хук произносится за ≤ 3 с, тема — в первых 5 словах.

Пиши **3 хука по 3 разным формулам**, оцени каждый, лучший — в сценарий, два других — в «Другие хуки».

| # | Формула | Шаблон | Пример |
|---|---|---|---|
| 1 | Всё ещё застрял | Ты [делаешь усилие] — и всё равно [плохой результат]. | Ты чистишь кэш каждую неделю — а телевизор всё равно тормозит. |
| 2 | Скрытая цена | [Обычная привычка] стоит тебе [конкретной потери]. | Каждый запрос к Claude Code стоит тебе тысяч лишних токенов. |
| 3 | Их слова | «[Фраза, которую зритель реально говорит]». [Короткий ответ-переворот]. | «Мне не нужен граф кода». Пока твой агент не перечитал проект в пятый раз. |
| 4 | Переворот | [Привычный совет/инструмент] — вот почему у тебя [проблема]. | Умный телевизор — вот почему у тебя реклама перед Netflix. |
| 5 | Хватит | Хватит [привычное действие]. [Сделай это] вместо. | Хватит платить за монтаж шортсов. Пусть его делает ИИ. |
| 6 | Ошибка | Одна [настройка/привычка], которая [убивает результат]. | Одна галочка в настройках сливает твои данные рекламщикам. |
| 7 | Задом наперёд | Ты [делаешь X] задом наперёд. | Ты ищешь баги по файлам, а надо — по связям. |
| 8 | Посреди сцены | [Когда], [где], [что идёт не так] — без вступления. | Два часа ночи, дедлайн утром, а агент опять читает весь репозиторий. |
| 9 | Как — без боли | Как [результат] без [боли, которую ждут]. | Как убрать рекламу с телевизора без рута и проводов. |

**Надпись-хук на экране** (кадр 0, она же обложка): ≤ 6 слов, одно слово выделено акцентом, **дополняет** голос, а не повторяет его дословно. Пример: голос «Claude Code каждый раз перечитывает весь проект — и сжигает токены», экран «Claude Code *сжигает токены*».

**Никогда не начинай с:** приветствия, имени, «в этом видео», «сегодня покажу», «давай поговорим»; вопроса с очевидным ответом («Хочешь больше просмотров?»); «А вы знали» + общеизвестного факта; контекста перед болью («Недавно я думал…»); обещания, которое тело ролика не выполняет.

### Оценка хука (0–2 за пункт, итого из 10, брать ≥ 7)

| Пункт | 0 | 1 | 2 |
|---|---|---|---|
| Конкретика | абстракция («расти быстрее») | есть деталь | цифра, название, сцена |
| Напряжение | утверждение | лёгкое любопытство | разрыв, ставка, противоречие, которое хочется закрыть |
| Зритель | только про продукт | зритель подразумевается | зритель узнаёт себя («ты») |
| Скорость | > 15 слов | 12–15 слов | ≤ 12 слов, тема в первых 5 |
| Честность | тело не выполняет | отчасти | тело даёт ровно обещанное |

Показывай как `хук 8/10` и называй слабый пункт, если он < 2 («Зритель 1: скажи „ты“»). Все три < 7 — напиши ещё три.

## Тело

Каркас «Боль → решение» для обзора инструмента:
1. **Хук** (боль + обещание).
2. **Что это** — одной фразой, для кого.
3. **Как работает** — показать на реальном продукте (скриншот, вывод команды, демо).
4. **1–2 фишки** — конкретно, с цифрой или примером.
5. **Повторный крючок** на 40–60% ролика: одна строка, перезапускающая внимание — новая цифра, поворот («Но главное не это»), самая сложная часть. Для ролика < 25 с можно опустить.
6. **Доказательство + честная оговорка** — цифра роста или цитата человека (Threads/X/HN) и одно реальное ограничение. Оговорка повышает доверие.
7. **Финал** — призыв один раз одной строкой («Ссылка в описании, сохрани») **или петля**: последняя строка подводит к первой, чтобы повтор ощущался непрерывным (финальный кадр повторяет кадр хука). Никогда: «спасибо за просмотр», «пишите в комментариях» (если не просим одно конкретное слово), пересказ сказанного.

## Триггеры (минимум четыре, на своих местах)

| Триггер | Где | Что делает |
|---|---|---|
| Разрыв любопытства | хук | открывает вопрос, который закрывается только в конце |
| Узнавание | хук или строка 2 | зритель видит свою ситуацию или свои слова |
| Доказательство | до 8-й секунды | цифра, экран, реальный вывод — почему верить |
| Враг | боль | привычка, инструмент или миф — никогда не сам зритель |
| Слом шаблона | повторный крючок, 40–60% | поворот или цифра, сбрасывающие внимание |
| Конкретика | решение | названия, команды, шаги — так, чтобы хотелось повторить |
| Потеря | перед призывом | что зритель продолжает терять без этого; без фальшивого дефицита |

Под сценарием подпиши: `Триггеры: разрыв 0с, узнавание 0с, доказательство 6с, …`

## Факты

Каждое число, название, результат — из `research/RESEARCH.md` со ссылкой. Нет источника — в ролик не идёт. Не округлять в большую сторону, не писать «исследования показывают».

## Проверки качества (до показа; провал — переписать, не показывать с оговоркой)

1. **Шаблонность.** Могла бы эта строка стоять в любом ИИ-сценарии про любой инструмент? В каждом ролике есть то, что есть только у этого проекта: его цифра, его реальный экран, его команда, цитата его пользователя.
2. **Структура.** Назови формулу хука, повторный крючок и триггеры. Хук обещает A, а тело даёт B — провал. Одно обещание от хука до призыва.
3. **Взаимозаменяемость.** Подставь другой инструмент той же ниши. Сценарий подходит так же хорошо — добавь конкретику проекта, пока не перестанет.
4. **Ритм.** Хук ≤ 3 с, нет строки > 4 с, смена на экране каждые 4–5 с, общая длина 30–40 с. Если дан эталон (`research/reference/REFERENCE.md`), ритм — по нему.

## SCRIPT.md (для человека)

Хуки (3 варианта с оценкой и формулой) → надпись-хук на экране → таблица сцен: `id | текст озвучки | что на экране | источник` → триггеры → `хук N/10 · слов · ~секунд`.

## script.json (для инструментов)

```json
{
  "language": "ru",
  "hook": "A",
  "hook_options": { "A": "…", "B": "…", "C": "…" },
  "pronounce": { "HyperFrames": "Хайперфреймс" },
  "scenes": [
    { "id": "hook", "say": "…", "sfx": [{ "file": "pop", "word": 10, "vol": 0.35 }] },
    { "id": "what", "say": "…" }
  ]
}
```

- `id` — латиница, коротко (`hook`, `what`, `how`, `f1`, `proof`, `cta`); это же имя файла сцены и id композиции.
- `say` — **экранное** написание (так будет в субтитрах). Произношение — через `pronounce` (проект) поверх `channel.json → pronounce` (канал). Тире «—» допустимы и нужны для пауз.
- Числа пиши цифрами («70 000», «450»), TTS прочтёт сам; если прочёл неверно — добавь в `pronounce` словами.
- `sfx` — звуки на номера слов сцены (`scenes.py` расставит и пересчитает после переозвучки).
