# Сборка сцен

Контракт HyperFrames — в `/hyperframes` (SKILL.md, `references/format.md`, `references/motion.md`, `references/types/vertical.md`). Здесь — то, что важно для этого канала.

## Кадр 1080×1920

- Контент — в полосе **220–1060 px** по вертикали, поля 90 px. Субтитры занимают ~1100–1300 px (низ группы — 640 px от низа кадра). Ниже 1330 px — только фон (там интерфейс Reels/Shorts).
- Текст ≥ 28 px; заголовки 110–150 px, Montserrat-подобный display 800, трекинг −0.03…−0.04em.
- Один акцент на кадр.

## Заготовка сцены (от scenes.py)

- В файле есть `DUR`, блок слов `W` (локальное время, номер и текст слова в комментарии) и `w(i)` / `we(i)`. Вешай появление элемента на номер слова, которое его называет: `tl.fromTo("#what-logo", {…}, {…}, w(3))`. Никаких секунд руками — после переозвучки `scenes.py` обновит `W`, и анимации сдвинутся сами.
- Видео можно собрать на черновом голосе (`voice.py --provider edge`), показать, и только после «ок» озвучить ElevenLabs: `voice.py` → `captions.py` → `scenes.py` → проверка.
- Каждая сцена: вход 0.25–0.45 с, выход за 0.2 с до конца слота (`DUR - 0.2`). Чередуй 3–4 типа переходов (blur-swap, сдвиг, зум из глубины, цветовая заливка), не один на все.
- `fromTo`, не `from`. Нет `Math.random`, `Date.now`, бесконечных `repeat`. Счётчики — `onUpdate` с `textContent`.
- Id элементов с префиксом сцены (`#what-title`). Стили и скрипт — внутри `<template>`.
- Кикер: `<div class="kicker">✱ …</div>` (2–4 слова).

## Кадр 0 и петля

- Кадр 0 = обложка: на нём уже стоит **надпись-хук** из SCRIPT.md (≤ 6 слов, одно слово акцентом) и картинка боли — без входа из пустоты (`first_frame_empty` в check — ошибка).
- Последний кадр перекликается с первым (тот же экран/объект в «исправленном» виде), чтобы повтор ролика ощущался непрерывным.
- Если есть `research/reference/REFERENCE.md` — интервал визуальных битов и длину бери оттуда.

## Реальный продукт

- Скриншот: `<img src="assets/shots/x.png">` внутри обёртки с `overflow: hidden` и скруглением; двигай обёртку (`scale`, `x`, `y`) — наезд на нужный элемент к слову, которое о нём говорит.
- Длинная страница: прокрутка `full-page.png` по `y` линейно, 2–4 с.
- Видео/GIF из README: `<video muted playsinline class="clip" data-start data-duration>` (GIF сначала в mp4: `ffmpeg -i a.gif -movflags faststart -pix_fmt yuv420p -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" a.mp4`).
- Логотип — только настоящий файл, не перерисовывать.

## Звуки

- Свуши на склейках ставит `scenes.py`.
- Звуки на действия задавай в `script.json → scenes[].sfx`: `{"file": "pop", "word": 3, "vol": 0.35}` — `scenes.py` поставит их на время слова и пересчитает после переозвучки. Вручную ниже `<!--/SFX-->` — только то, что не привязано к слову.
- Звуки: `pop` — плашка/число встаёт, `click-soft` — чип/кнопка, `typing` — печать кода (обрежь `data-duration`), `sparkle` — один раз на кульминации. Громкость 0.3–0.45, у каждого `data-duration` = длине файла (pop 0.72, click-soft 0.37, sparkle 1.8, typing 1.5, whoosh 0.57) и свой `id`; одинаковые звуки, идущие внахлёст, — на разные `data-track-index` (5, 6).
- Музыки нет (не подключена) — не генерировать.

## Финальная сцена (cta)

Логотип проекта + название + плашка с адресом (моно) + «Сохрани» с иконкой закладки (заполняется акцентом на слове). Держится ≥ 1.4 с после последнего слова (`end_hold`).
