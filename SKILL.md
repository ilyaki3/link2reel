# /short — ролик о проекте

Вход: ссылка (сайт, GitHub, Product Hunt…) или название инструмента. Флаг `--auto` — без остановки на сценарии. Необязательно: `--like <ссылка или файл>` — эталонный вирусный ролик, под ритм которого подстроиться (шаг 2б).
Перед сборкой прочитай навык `/hyperframes` (контракт композиции) и `references/build.md`.

Настройки канала — `channel.json` в папке навыка: папка роликов, язык, голос (`voice_id`, `speed`, `gap`), ник, словарь произношения. Инструменты — `tools/` (запускать `python3 <путь навыка>/tools/…`).

## 0. Проверка окружения (один раз за сессию)

- Голос по умолчанию — **ElevenLabs**, ваш голос из `channel.json → voice.voice_id` (свой, созданный в Voice Design, или встроенный), модель `eleven_v4`, ускорение `speed` 1.2 через atempo после синтеза (rubberband не использовать — звучит электронно) (`channel.json → voice`). Ключ — `$ELEVENLABS_API_KEY` в `~/.zshrc`.
- **Бесплатный тариф: 10 000 символов в месяц, голоса из библиотеки через API недоступны** — только встроенные и созданные самим пользователем. Символы берегут: не генерировать пробы и дубли без просьбы; переозвучивать только изменённую сцену (`--only`). Перед озвучкой проверь остаток: `curl -s https://api.elevenlabs.io/v1/user/subscription -H "xi-api-key: $ELEVENLABS_API_KEY"` → `character_limit - character_count`; ролик ≈ 600–800 символов.
- Запасные: `--provider heygen` (нужен `npx hyperframes auth login`; русские голоса слабые) и `--provider edge` (только черновик).

## 1. Проект

`bash <навык>/tools/new_project.sh <slug>` — создаёт `<videos_root>/<дата>-<slug>/` (HyperFrames, шаблон канала, шрифты с кириллицей, звуки). Дальше всё внутри этой папки.

## 2. Ресерч → `research/RESEARCH.md`

Подробно: `references/research.md`. Коротко:
- Первоисточник: сайт / README / docs; для GitHub — `gh api repos/<o>/<r>` (звёзды, лицензия, язык, дата), релизы, README.
- Отзывы: обзоры и HN (`hn.algolia.com/api/v1/search?query=`), Reddit, **Threads и X — через встроенный браузер** (только чтение; стена логина → пропусти и отметь).
- Итог: что это в одной фразе, для кого, 3–5 фишек, цифры, 2–3 живые цитаты людей, минусы/подводные камни. **Каждый факт — со ссылкой.** Без источника — в ролик не идёт.

## 2б. Эталон «как в этом ролике» (если дан `--like` или пользователь прислал ролик-образец)

`python3 <навык>/tools/reference.py <проект> <файл.mp4 | URL>` → `research/reference/REFERENCE.md` + `sheet.jpg`. URL качается через `yt-dlp`, если он стоит; нет — попроси файл (Instagram часто требует вход) или разрешение на `brew install yt-dlp`. Посмотри `sheet.jpg` и заполни раздел «Что перенести»: длина, интервал визуальных битов, что в кадре 0, стиль субтитров. Дальше сценарий и сцены подстраиваются под эти цифры (в рамках 30–40 с и правил канала). Копируем ритм и приёмы, а не чужой текст и не чужие кадры.

## 3. Стиль → `STYLE.md` и `:root` в `index.html`

Подробно: `references/style.md`. Облик берётся у проекта (цвета, шрифт, логотип, реальные скриншоты/демо), слой канала (субтитры, кикеры, safe-зоны, финальная карточка) не меняется.

## 4. Сценарий → `SCRIPT.md` + `script.json`

Подробно: `references/script.md`. 30–40 с (≈75–80 слов: голос ×1.2 читает ~2,2 слова/с), 6–9 сцен по 3–6 с, бит каждые 2–3 с. **Три хука, все через боль** (см. script.md).

**Вычитка перед показом** (навык `/humanizer-ru`, режим редактуры, регистр «посты/соцсети»): собери все `say` в файл и прогони сканер `python3 ~/.claude/skills/humanizer-ru/scripts/scan.py research/say.txt`, затем правь по его процедуре. **Тире «—» в `say` не трогать** — это паузы голоса (правило записано в edit-log навыка). Факты, цифры и названия не меняются. Цель — чистота ≥ 85 без учёта штрафа за тире. Обнови `say` в script.json и SCRIPT.md.

**Стоп:** покажи пользователю бриф (что это, главные факты с источниками, цитаты), 3 хука через боль — каждый с формулой и оценкой `хук N/10`, — надпись-хук для кадра 0 (≤ 6 слов) и сценарий по сценам с описанием картинки, триггерами и длиной. Перед показом прогони 4 проверки качества из `references/script.md`. Жди выбора хука и правок. С `--auto` — выбери лучший хук сам и продолжай.

## 5. Озвучка и субтитры

```bash
python3 <навык>/tools/voice.py <проект>            # ElevenLabs по сценам → assets/voice.wav, timeline.json
python3 <навык>/tools/captions.py <проект>         # субтитры → compositions/captions.html, deliver/captions.srt
python3 <навык>/tools/scenes.py <проект>           # хосты сцен, длительность, свуши, заготовки сцен
```
Прочитай вывод `captions.py`: каждая группа — осмысленные 2–3 слова, экранное написание верное (HyperFrames, а не «Хайперфреймс»). Ошибка ударения/произношения → добавь в `script.json → pronounce` и переозвучь только сцену: `voice.py <проект> --only <id>`, затем снова `captions.py` и `scenes.py`.
Длина вышла за 40 с → сократи текст, а не ускоряй голос сверх 1.2.

## 6. Сцены

Заполни `compositions/<id>.html` по `references/build.md`: анимации привязаны к словам через `at(время)`, реальный продукт в кадре минимум в двух сценах, кадр 0 — хук (это обложка). Звуки на действия — в `index.html` ниже `<!--/SFX-->`.

## 7. Проверка и рендер

1. `npx hyperframes check --json` — исправь все ошибки, взвесь предупреждения.
2. `npx hyperframes snapshot --at <по кадру на сцену> --no-end` — посмотри контакт-лист: кириллица не подменена засечками, текст в зоне 168–1330 px, ничего не налезает на субтитры.
3. `npx hyperframes render -o deliver/video.mp4 -q delivery -w 2` (в фоне; 8 ГБ памяти — не больше 2 воркеров).
4. Громкость: `ffmpeg -i deliver/video.mp4 -af ebur128=peak=true -f null -` → около −16…−14 LUFS.

## 8. Пакет → `deliver/`

- `video.mp4`, `captions.srt` (уже есть), `cover.png` — `npx hyperframes snapshot --at 0.3 --no-end -o deliver/_cover` и перенеси кадр в `deliver/cover.png`.
- `POSTS.md`: заголовок YouTube Shorts (≤ 60 симв.), описание; подпись Reels (первая строка — крючок, ссылка «в описании/в био»); подпись TikTok; 5–8 хэштегов; список источников. Тексты постов (без ссылок, хэштегов и источников) прогони через `/humanizer-ru` так же, как сценарий; здесь тире снимаются как обычно.

Отчёт пользователю: файл видео (SendUserFile), длина, что проверено и чем, что не проверено (звук измерен, а не прослушан).
